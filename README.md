# <img src="public/images/logo.png" height=25> SocialHop — Connect. Share. Explore.

**SocialHop** is a modern full-stack social media platform designed to help users **connect**, **share content**, and **explore trending topics** — all through a fast, intuitive, and responsive interface.

With support for **image, video & text posts**, **real-time interactions**, and **profile customization**, SocialHop makes social networking seamless and engaging.

---

## ✨ Key Features

- **Post Text, Images & Videos**  
  Share your thoughts, photos, and videos effortlessly with a beautiful, responsive feed.

- **Like & Comment System**  
  Interact with other users through likes and comments, fostering real-time discussions.

- **Profile Management**  
  Upload a profile picture and banner, manage your followers/following, and personalize your public profile.

- **Trending Hashtags**  
  Discover popular hashtags and explore the hottest conversations happening right now.

- **Follow Suggestions**  
  Get intelligent recommendations on who to follow to grow your network.

- **Light/Dark Theme Toggle**  
  Seamlessly switch between light and dark modes to match your preference.

- **Responsive Design**  
  Optimized for all devices — from mobile to desktop — for a smooth user experience everywhere.

## 🛠 Tech Stack

| Category         | Technologies                            |
|------------------|-----------------------------------------|
| **Frontend**     | Next.js 14/15 (App Router), Tailwind CSS, ShadCN UI |
| **Backend**      | Node.js, Next.js API Routes            |
| **Database**     | Supabase (PostgreSQL), Prisma ORM      |
| **Auth**         | Clerk                                   |
| **Media Upload** | Cloudinary                              |
| **Hosting**      | Vercel                                  |
